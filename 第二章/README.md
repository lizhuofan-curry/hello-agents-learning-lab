# 第二章｜没有大模型，也能“聊天”吗？

从 ELIZA 开始，看看规则系统如何制造“它理解我”的感觉。这两份脚本很适合先运行、再故意输入规则之外的句子：表面流畅的回应和真正理解之间，差距会变得具体。

> 你说“我最近在学习 Python”，它可能接着问“学 Python 哪里最难？”——听起来像在倾听，其实只是正则命中、模板填空与随机挑句。

## 这章想回答的三个问题

- 没有语言模型，程序为什么也能给出貌似自然的回应？
- 一条规则能覆盖多少种说法；超出规则时会怎样？
- 给机器人加入姓名、年龄和职业的短期记忆后，它真的“理解”了吗？

## 代码入口

| 文件 | 观察点 |
|---|---|
| [ELIZA 聊天机器人.py](./ELIZA%20聊天机器人.py) | 正则规则、模板回复、代词转换与兜底回应 |
| [升级版EILIZA聊天机器人.py](./升级版EILIZA聊天机器人.py) | 按工作、学习、爱好等主题扩展规则，并用字典保存姓名、年龄、职业；文件名保留原拼写 |

两个脚本主要使用 Python 标准库，可以在仓库根目录直接运行：

```powershell
python ".\第二章\ELIZA 聊天机器人.py"
python ".\第二章\升级版EILIZA聊天机器人.py"
```

这是交互式对话示例，启动后按脚本提示输入英文句子。建议试试同一句话的不同说法，再输入完全不匹配的句子，观察规则覆盖范围和兜底回复。

## 亲自做一次“图灵小实验”

先对原版输入 `I need help`，再对升级版输入 `I am studying Python`；然后告诉升级版你的名字，再问它你的名字是什么。最后故意换一种它不认识的句式。你会看到三种不同机制：模板匹配、简短记忆和兜底答复。输入 `quit`、`exit` 或 `bye` 可以结束聊天。

可以进一步把 `rules` 中一条规则删掉再运行：机器人的“性格”会突然变化，但知识并没有真的增加。升级版的记忆也只在本次运行的字典里，不是长期记忆或语义理解。
